# CyberOps X Frontend

This is the React frontend for the CyberOps X unified cybersecurity platform.

## Tech Stack
- **React 18**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Recharts** (Data Visualization)
- **React Router Dom**
- **Axios**

## Setup Instructions
1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
